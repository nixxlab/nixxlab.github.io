Её разбивают на две строки жёстким переносом.

## Заголовок раздела стоит по центру

Код внутри текста, например `defer`, набран золотом в размер букв. Блок кода — так же:

```
name := fn(a : u64) -> u64 { a }
```

Запись заканчивается последним абзацем, без линии и постскриптума.
